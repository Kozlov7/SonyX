# Вопросы и решения

## Решено

| Вопрос | Решение | Когда |
|---|---|---|
| Переделывать Kordon? | Нет. Код закрыт, лицензия запрещает разбор и изменённые сборки. Пишем своё с нуля. | 05.11.2026 |
| Telegram и чужой сервер | Не нужны. Уведомления — штатные macOS. | 05.11.2026 |
| Какие программы защищать | Chrome (целиком), Cursor, Claude Code в терминале. | 05.11.2026 |
| Режимы | Два: обычный (туннель + страна) и жёсткий (+ смена адреса). | 05.11.2026 |
| Фиксировать IP? | Не жёстко. Адрес и страна запоминаются при включении защиты, новые подтверждаются кликом. Смену адреса внутри страны ловит только жёсткий режим. | 05.11.2026 |
| Другой VPN-клиент | Подойдёт любой с туннелем (`utun`). Клиенты «только прокси» не поддерживаются. | 05.11.2026 |
| Happ: TUN | Включён Xray TUN, иначе терминал шёл мимо прокси. Маршрут по умолчанию через `utun66`. | 05.11.2026 |
| Проверка IPv6 | Локальная, без запросов наружу. На тестовом Mac публичного IPv6 нет. | 05.11.2026 |
| Запросы к Anthropic фоном | Нет. Страна определяется локально по адресу сервера VPN и базе GeoIP. | 05.11.2026 |
| Платформа | Первая версия только macOS. | 05.11.2026 |
| Идеи из trust-ip.dialogic-ai.ru | Сервис браузерный, всё через внешние запросы — подход не копируем. Берём два: встроенный список стран сервисов и проверку через сам `claude.ai`. Балл репутации IP, WebRTC, внешний DNS, статус-страницы — не берём. | 06.11.2026 |
| Запрос к `claude.ai` по кнопке | Допустим. Делает сам SonyX без cookie, только при туннеле. Адрес VPN Anthropic и так видит каждый день, новой информации нет. Спрашиваем сам сервис, а не `1.1.1.1`: нейтральный хост не покажет маршрутизацию по доменам. Фоном по-прежнему не ходим. | 06.11.2026 |
| Список стран для Cursor | Cursor своего списка не публикует, отсылает к спискам провайдеров. Показываем «по правилам Anthropic» с пометкой про Россию и страны под эмбарго США. | 06.11.2026 |
| Интерфейс | Только строка меню, без Dock и главного окна. Монохромные символы вместо цветных значков. Настройки — одна страница. Кнопки «+ Текущий адрес» / «+ Текущая страна». Описание в ARCHITECTURE.md. | 06.11.2026 |
| IPv6 наружу | Это утечка, а не предупреждение: пауза в обоих режимах. Chrome предпочитает IPv6, `claude.ai` его поддерживает. | 06.11.2026 |
| Часовой пояс | Строчка в окне, на значок не влияет: исправить нельзя, постоянное предупреждение обесценило бы значок. | 06.11.2026 |
| База GeoIP | DB-IP Lite Country: свободная лицензия CC BY 4.0, скачивается без регистрации, обновляется ежемесячно. GeoLite2 отвергнута из-за регистрации и ключей при сборке, `geoip.dat` от Happ — из-за привязки к одному клиенту. | 06.11.2026 |
| Закрытие терминала | SIGHUP обрабатывается так же, как Ctrl-C: всё отпускается. От `kill -9` защищает `state.json` и `sonyx release`. | 06.11.2026 |
| Формат настроек | JSON (`config.json`), не YAML: без зависимостей. | 06.11.2026 |
| Страна сервера vs выхода | Страна по адресу сервера нужна для обнаружения смены сервера; настоящий выход берётся из проверки 6 и запоминается на каждый сервер. Подтверждено: сервер CY по базе, выход DE. | 06.11.2026 |
| Режим фокусирования | Уведомления должны проходить. Time-sensitive при подписанной сборке, иначе ручное добавление SonyX в разрешённые приложения фокуса с подсказкой при первом запуске. | 06.11.2026 |
| Режимы (пересмотр) | Три вместо двух: лёгкий (пауза только в запрещённых странах — встроенный список + чёрный список), средний (только разрешённые страны), жёсткий (только разрешённые адреса сервера). Решение по стране **выхода**, не сервера. | 07.11.2026 |
| Запрос к `claude.ai` фоном (пересмотр) | Допустим автоматически: при новом сервере, переподключении и раз в 30 мин (настраивается, можно выключить). Без него лёгкий и средний режимы с автовыбором сервера дают ложные паузы. Запрос привязан к интерфейсу туннеля и мимо него уйти не может. Раз в минуту технически безвредно, но против принципа «минимум наружу»; оставлено на выбор пользователя. | 07.11.2026 |
| Статичный IP | SonyX не может сделать выход стабильным — только заметить смену. Стабильность делается в VPN-клиенте (один закреплённый сервер) или собственным сервером, где адрес подключения = адрес выхода. Тихая подмена выхода без обрыва ловится не быстрее интервала перепроверки — это осознанное слепое окно. | 07.11.2026 |
| Уведомления | Три переключателя: смена страны (вкл), смена адреса (выкл), заморозка/разморозка (вкл). За одну проверку — одно сообщение, события объединяются. | 07.11.2026 |
| Тесты в репозитории | Не переносим: автотест нужен только на время разработки, живёт в `~/AIprojects/sonyx-e2e`. | 07.11.2026 |

## Открытые вопросы

1. **Если туннель не вернулся за 20 секунд** — программы остаются замороженными
   или закрываются, как в Kordon?
   Предложение: остаются замороженными. Ничего не теряется, а вернувшийся туннель
   отпустит их сам.

2. **Язык программы.** Swift с самого начала или сначала shell-прототип?
   Предложение: Swift. Окно в строке меню и уведомления с кнопками иначе не сделать,
   а прототип на shell пришлось бы выбросить.

3. **Лицензия для GitHub.** MIT (можно всё, включая закрытые форки) или GPL-3.0
   (изменённые версии обязаны оставаться открытыми)?
   Предложение: GPL-3.0, раз главная ценность проекта — открытость и проверяемость.

4. **Проверка новых версий.** Один запрос к GitHub раз в день выдаёт GitHub ваш адрес.
   Делать её, делать только по кнопке или не делать вовсе?
   Предложение: только по кнопке «Проверить обновления».

5. **Имя SonyX.** Надо проверить, не занято ли на GitHub и не путается ли с чужими
   товарными знаками (Sony). Если есть риск — подобрать другое до публикации.

6. **Платный аккаунт Apple Developer** (99 $ в год) для подписи и нотаризации.
   Без него пользователям придётся разрешать запуск вручную в настройках безопасности.
   Нужен ли на старте или позже?
   Дополнительный довод «за»: уведомления уровня time-sensitive, проходящие сквозь
   режим фокусирования, требуют подписи с разрешением Apple. Без них пользователю придётся
   один раз добавить SonyX в разрешённые приложения фокуса руками.

## Открытые технические вопросы (решу сам на этапе прототипа)

- ~~Как надёжно найти адрес сервера VPN.~~ Решено на этапе 3: `ServerDetector`,
  описание в CHECKS.md, проверка 2. Остаётся наблюдать: у Happ одновременно два
  «тяжёлых» сервера (`192.0.2.42` ×29 и `192.0.2.82` ×18); если лидерство будет
  скакать между ними, обычный режим один раз спросит про вторую страну, жёсткий —
  про второй адрес.
- Как часто Happ меняет страну сервера. 5 ноября выход был в Германии, 6 ноября —
  в Нидерландах. Если это каждый день, пользователь будет часто видеть вопрос
  «Разрешить страну?». Понаблюдать неделю на прототипе.
- Как отличить «Mac проснулся, туннель ещё поднимается» от «туннель упал»,
  чтобы не слать лишние уведомления при коротких морганиях.
- Поведение, когда Chrome заморожен, а пользователь кликает по его окну:
  macOS может показать «не отвечает». Нужно предупреждать в окне SonyX.
- Что делать с процессами защищаемой программы, которые запущены от другого
  пользователя или от администратора (SonyX их заморозить не сможет).
