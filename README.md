# SonyX

Сторож для программ на Mac, которым нельзя выходить в интернет мимо VPN.

Пропал туннель, сменилась страна или адрес — SonyX за долю секунды ставит выбранные
программы на паузу. Туннель вернулся — программы продолжают с того же места,
ничего не теряется. Остальной интернет работает как обычно.

Без Telegram, без чужих серверов, без аналитики. Все проверки делаются на самом Mac.

## Зачем

Сервисам ИИ важно, откуда вы заходите. VPN рвётся постоянно: после сна,
при смене Wi-Fi, при переподключении. В эту секунду Claude или Cursor уже
отправляют запрос с настоящего адреса, а вы узнаёте об этом последним.

Kill switch внутри VPN-клиента рубит интернет целиком, и у Happ на Mac его нет.
SonyX работает точечно: трогает только выбранные программы и не закрывает их,
а замораживает.

## Что защищает в первой версии

- Google Chrome (целиком, со всеми вкладками)
- Cursor
- Claude Code в терминале (процесс `claude` и всё, что он запустил)

Список настраивается, любую программу можно добавить.

## Три режима

Во всех режимах: пропал туннель или IPv6 идёт мимо него — пауза. Режим решает только,
что делать со страной и адресом сервера.

| Режим | Пауза, если… | Кому подходит |
|---|---|---|
| **Лёгкий** | страна выхода в запрещённых: встроенный список стран, где Claude не работает, плюс ваш чёрный список | работает без настройки; VPN с автовыбором сервера |
| **Средний** | страна выхода не из разрешённых (или неизвестна) | «хочу только Германию» |
| **Жёсткий** | адрес сервера не из разрешённых | один закреплённый сервер в VPN-клиенте |

Решение принимается по стране **выхода** — той, которую видит сайт, — а не по стране
сервера, к которому подключён VPN-клиент: это часто разные страны (цепочка серверов).
Выход SonyX узнаёт сам, одним запросом к `claude.ai` при появлении нового сервера,
при переподключении и раз в 30 минут (настраивается).

## Как пользоваться (консольная версия)

Собрать один раз: `swift build` в папке проекта. Команды — из Terminal.app, не из
терминала Cursor (своих «предков» SonyX не замораживает). Вместо `sonyx` пока пишется
`.build/debug/sonyx`.

**Каждый день**

| Команда | Что делает |
|---|---|
| `sonyx watch` | Включить защиту и следить. Окно держать открытым; Ctrl-C — выключить и всё отпустить |
| `sonyx status` | Показать текущее состояние: туннель, сервер, страна выхода, что заморожено |
| `sonyx log` | Последние 30 строк журнала (`sonyx log 100` — сто) |

**Настройка**

| Команда | Что делает |
|---|---|
| `sonyx mode light` / `medium` / `strict` | Выбрать режим: лёгкий / средний / жёсткий |
| `sonyx allow country DE` | Разрешить страну (для среднего режима). Код — две буквы: DE, NL, FR… |
| `sonyx disallow country NL` | Убрать страну из разрешённых |
| `sonyx allow ip 1.2.3.4` / `disallow ip …` | Разрешить или убрать адрес сервера (для жёсткого режима) |
| `sonyx allow current` | Разрешить сервер и страну, через которые работаете прямо сейчас |
| `sonyx deny country TR` / `undeny country TR` | Запретить или разрешить страну (чёрный список для лёгкого режима) |
| `sonyx autocheck on` / `off` | Сторож сам проверяет страну выхода (по умолчанию включено) |
| `sonyx recheck 30` | Как часто перепроверять выход на одном сервере, минуты; 0 — не перепроверять |

**Если что-то пошло не так**

| Команда | Что делает |
|---|---|
| `sonyx release` | Отпустить всё, что SonyX заморозил, если он упал и не отпустил сам. `--all` — вообще все остановленные процессы защищаемых программ |
| `sonyx exit-check` | Спросить `claude.ai`, какой адрес и страну он видит прямо сейчас |
| `sonyx selftest` | Проверить, что заморозка работает, на безвредном процессе |
| `sonyx geo 1.2.3.4` | Страна адреса по встроенной базе |

Типичный сценарий: Chrome встал на паузу, в журнале «сервер … в стране X — она не
разрешена» и строка «что делать» с готовой командой. Если X — правильная страна,
выполняете команду, через секунду Chrome отпущен. Если нет — переключаете сервер в VPN.

Файлы: `~/Library/Application Support/SonyX/` — `config.json` (настройки), `sonyx.log` (журнал).

## Принципы

1. **Ничего лишнего наружу.** Фоновые проверки туннеля, адреса, DNS и IPv6 не отправляют
   ни одного пакета. Единственный запрос наружу — «какой адрес видит сайт» к `claude.ai`:
   без cookie, только когда туннель поднят, и физически привязан к туннелю, так что мимо него
   уйти не может. Делается при новом сервере, переподключении и раз в 30 минут; отключается.
2. **Сначала пауза, потом проверка.** При старте, после сна и при любом событии сети
   программы замораживаются, пока проверка не прошла.
3. **Заморозка, а не закрытие.** Штатная пауза процесса (`SIGSTOP` / `SIGCONT`).
   Данные и незаконченный ответ ИИ не теряются.
4. **Открытый код.** Проект будет выложен на GitHub под свободной лицензией.

## Откуда идея

Идея подсмотрена у [Kordon](https://efimovdev.ru/kordon) — закрытой бесплатной
программы с обязательным входом через Telegram и своим сервером. SonyX делает
то же самое без входа и без сервера. Код Kordon не использовался и не разбирался:
SonyX пишется с нуля по собственному описанию.
