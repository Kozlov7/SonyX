# Устройство SonyX

## Платформа и язык

Первая версия только для macOS. Предлагаемый язык — Swift.

Почему Swift, а не shell или Go:
- окно в строке меню и уведомления с кнопками делаются штатно, без зависимостей;
- подписка на события сети (SystemConfiguration, Network.framework) родная;
- один бинарник, подписанный как обычное приложение Mac;
- shell-скрипт хорош для прототипа, но окно на нём не сделать, и переписывать
  придётся всё равно.

Решение не окончательное, см. QUESTIONS.md.

## Из чего состоит

```
SonyX.app
├── Core (ядро, без интерфейса)
│   ├── NetworkWatcher    — события сети (SCDynamicStore)
│   ├── PowerWatcher      — сон и пробуждение (IOKit)
│   ├── Guardian          — цикл «проверил → отреагировал», страховочный опрос
│   ├── TunnelCheck       — проверка 1 (маршрут по умолчанию)
│   ├── Connections       — список соединений, ServerDetector — проверка 2 (сервер VPN)
│   ├── Diagnostics       — проверки 3–5 (IPv6, DNS, часовой пояс), ExitCheck — проверка 6
│   ├── ServiceRegions    — проверка 8 (страны Claude / ChatGPT / Cursor)
│   ├── GeoIP             — локальная база «адрес → страна» (DB-IP Lite, Resources/geoip-v4.bin)
│   ├── ProcessManager    — поиск процессов, дерево, SIGSTOP / SIGCONT
│   ├── Config, Policy    — настройки, три режима (лёгкий / средний / жёсткий), списки стран и адресов
│   ├── State             — файл с замороженными PID и последним состоянием
│   └── Logger            — журнал событий в файл
├── UI (строка меню)
│   ├── Значок состояния  — работает / пауза / предупреждение / выключено
│   ├── Окно показателей  — туннель, адрес, страна, IPv6, DNS, что под защитой
│   └── Настройки         — программы, режим, разрешённый список, автозапуск
└── CLI `sonyx`           — status, watch, mode, allow/disallow, deny/undeny, autocheck, recheck, exit-check, release, log
```

Ядро и интерфейс разделены: ядро можно запускать без окна как фоновый процесс.

## Интерфейс

Принцип: поставил, включил VPN — и забыл. Всё общение через значок в строке меню
и редкие уведомления. Значка в Dock нет, главного окна нет. Если настройки
открываются чаще раза в месяц, дизайн неправильный.

### Установка и первый запуск

1. Скачать `SonyX.zip`, перетащить в «Программы», открыть. Пароль администратора
   не нужен: заморозка своих процессов — обычная операция, без root и расширений ядра.
2. macOS спросит разрешение на уведомления.
3. SonyX спросит: «Запускать при входе в систему?» Больше вопросов нет.
4. Туннель поднят → SonyX запоминает страну и адрес, уведомление «Защита включена.
   Германия. Под защитой: Chrome, Cursor, Claude Code». Туннель не поднят → значок
   «выключено», подпись «Включите VPN, защита начнётся сама». При первом запуске
   замораживать нечего: эталонной страны ещё нет.
5. Подсказка про режим фокусирования (см. ниже).

### Значок в строке меню

Монохромные системные символы (SF Symbols), подстраиваются под светлую и тёмную тему.
Цветных значков нет — Apple сама не рекомендует их в строке меню.

| Состояние | Символ | Когда |
|---|---|---|
| Работает | щит с галочкой `checkmark.shield` | туннель есть, страна верная |
| Пауза | залитый щит с крестом `xmark.shield.fill` | туннель пропал, чужая страна/адрес, прямой маршрут IPv6 |
| Предупреждение | щит с восклицательным знаком `exclamationmark.shield` | DNS мимо туннеля; страна не в списке сервисов |
| Выключено | перечёркнутый щит `shield.slash` | защита выключена или на паузе пользователем |

Точные символы подбираются вживую. Часовой пояс на значок не влияет (см. CHECKS.md, проверка 5).

### Окно по клику на значок

Небольшое всплывающее окно, без вкладок:

```
[щит] Защита работает
      Германия · 203.0.113.10 · через utun66

Под защитой
   Google Chrome      работает
   Cursor             работает
   Claude Code        не запущен

!  DNS идёт через роутер (192.168.1.1)        ← только если есть
   Часовой пояс: Москва, не совпадает с Германией

Режим:  (•) Обычный   ( ) Жёсткий

[ Что видит сайт ]   [ Пауза на час v ]        [настройки]
```

В состоянии паузы шапка: «Туннель пропал · Chrome, Cursor на паузе · 00:14».
«Пауза защиты»: 15 мин / 1 час / до перезапуска.
«Что видит сайт» неактивна без туннеля, с подписью почему.

### Уведомления

Только когда нужно решение или прошло время:

- Туннель пропал → пауза мгновенно, но первые 3 секунды тишина: моргания при смене
  Wi-Fi не должны дёргать. Не вернулся → уведомление «Chrome и Cursor на паузе.
  Не закрывайте их принудительно — отпустит само, когда VPN вернётся».
- Новая страна или адрес → кнопки «Разрешить Германию», «Разрешить только этот адрес»,
  «Пауза защиты на час».
- Туннель вернулся → без уведомления, значок просто меняется.

**Режим фокусирования.** Приложение само не может пробиться через «Не беспокоить».
Два пути, делаем оба:
- уведомления с уровнем time-sensitive — проходят сквозь фокус, но требуют подписи
  с разрешением Apple (см. QUESTIONS.md, вопрос 6);
- пользователь один раз добавляет SonyX в разрешённые приложения режима фокусирования
  (Настройки → Фокусирование → режим → Разрешённые приложения). SonyX показывает
  подсказку с этим путём при первом запуске.
Значок в строке меню фокус не трогает — состояние видно всегда.

### Настройки

Одно окно, одна страница:

- **Программы** — список с галочками. Chrome, Cursor, Claude Code предустановлены.
  «+» открывает выбор из папки «Программы»; для терминальных (`claude`) — поле
  с именем процесса.
- **Режим** — лёгкий / средний / жёсткий, одна строка с объяснением разницы.
- **Разрешено** — страны и адреса, с крестиками для удаления. Кнопки
  «+ Текущий адрес» и «+ Текущая страна» — SonyX подставляет их сам из проверки 2.
  Ручное поле ввода тоже есть.
- **Запускать при входе** — переключатель.
- **«Что видит сайт»** — хост (по умолчанию `claude.ai`), галочка
  «подробная диагностика через 1.1.1.1».
- **Журнал** — кнопка «Открыть журнал».

Ни аккаунтов, ни облака, ни фоновой проверки обновлений.

### Чего намеренно нет

- Мастера настройки на несколько экранов.
- Главного окна и значка в Dock.
- Графиков и статистики (возможно, потом).
- CLI `sonyx` остаётся как инструмент отладки, обычный пользователь о нём не знает.

### Известные слабые места

- Замороженный Chrome выглядит зависшим; пользователь может полезть его убивать.
  Уведомление «не закрывайте принудительно» смягчает, но не решает.
- При каждой смене Wi-Fi возможна пауза на 2–3 секунды. Поэтому значок «пауза»
  и уведомление — с задержкой 3 секунды, хотя сама заморозка мгновенная.

## Как работает заморозка

- Штатная пауза процесса: `kill -STOP <pid>`, возврат — `kill -CONT <pid>`.
- Замораживается всё дерево: родитель и все потомки (у Claude Code это MCP-серверы,
  `git`, `curl`; у Cursor и Chrome — десятки вспомогательных процессов).
- Chrome замораживается целиком: все профили и вкладки живут в одном дереве процессов.
- Сам SonyX, VPN-клиент и системные процессы в список попасть не могут.
- Замороженная программа перестаёт отвечать, её окно «висит». Это нормально
  и видно по значку SonyX.

## Память о состоянии

Файл `~/Library/Application Support/SonyX/state.json`:
- какие PID сейчас заморожены и когда;
- последнее известное состояние (туннель, адрес, страна).

Зачем: если SonyX упал или его убили, при следующем запуске он найдёт
замороженные процессы и разморозит их (или проверит состояние и оставит).
Без этого программы остались бы висеть навсегда.

## Настройки

Файл `~/Library/Application Support/SonyX/config.json` — JSON, а не YAML: читается
штатными средствами без зависимостей.

```json
{
  "mode": "medium",
  "allowed": { "countries": ["DE"], "ips": ["192.0.2.50"] },
  "denied": { "countries": [] },
  "exits": {
    "192.0.2.50": { "ip": "203.0.113.11", "country": "DE", "checkedAt": "2026-11-07T11:48:31Z" }
  },
  "traceHost": "claude.ai",
  "autoCheck": true,
  "recheckMinutes": 30
}
```

- `mode` — три режима (с 07.11.2026). Во всех: туннель упал или IPv6 наружу — пауза. Различаются
  только правилом про страну и адрес:
  - `light` (лёгкий, по умолчанию) — пауза только в запрещённых странах: встроенный список стран,
    где Claude не работает, плюс `denied.countries`. Работает без настройки;
  - `medium` (средний) — пауза везде, кроме `allowed.countries`. Страна неизвестна — тоже пауза;
  - `strict` (жёсткий) — пауза везде, кроме `allowed.ips`. Имеет смысл только с одним закреплённым
    сервером в VPN-клиенте.
  Старое имя `normal` из файлов до 07.11.2026 читается как `medium`.
- `allowed` заполняется при первом запуске (текущий сервер и его страна) и командами
  `sonyx allow country XX` / `sonyx allow ip …` / `sonyx allow current`; убрать — `sonyx disallow`.
- `denied` — чёрный список для лёгкого режима: `sonyx deny country XX` / `sonyx undeny country XX`.
- `autoCheck`, `recheckMinutes` — автопроверка выхода (CHECKS.md, проверка 6): `sonyx autocheck on|off`,
  `sonyx recheck N`.
- Каждое поле читается отдельно; отсутствующее берётся по умолчанию, чтобы файл старой версии
  не ломался из-за нового поля.
- `exits` — что видит сайт через данный сервер, результат проверки 6. Если запись есть,
  решение о стране принимается по ней, а не по базе GeoIP (`CountryInfo`, см. CHECKS.md, проверка 2).
- Если файл есть, но не читается (например, лишняя запятая после ручной правки), SonyX
  работает с пустыми настройками, пишет ошибку в журнал и `status` и **ничего не сохраняет**:
  иначе «первый запуск» перезаписал бы файл и стёр разрешённые страны и адреса.
- Список программ пока зашит в коде (`ProtectedApp.defaults`); в настройки переедет
  на этапе 4 вместе с окном.
- Реакции на IPv6 и DNS не настраиваются: IPv6 наружу — всегда пауза, DNS мимо туннеля —
  всегда предупреждение (см. CHECKS.md).

Всё то же самое будет правиться из окна настроек.

## Что SonyX отправляет в сеть

Фоном — ничего. По кнопке «Что видит сайт» — один запрос, и только при поднятом туннеле.
Обновления: проверка новой версии — отдельный вопрос, пока не решён (см. QUESTIONS.md).

## Совместимость с VPN

Работает с любым клиентом, который поднимает туннель (`utun`) и ведёт через него
маршрут по умолчанию: Happ с включённым Xray TUN, WireGuard, OpenVPN, Amnezia и др.
Имя клиента знать не нужно.

Не работает с клиентами в режиме «только системный прокси» без туннеля:
проверка маршрута их не видит. Так было у Happ до включения Xray TUN.

## Распространение

- Репозиторий на GitHub, свободная лицензия (MIT или GPL-3.0 — см. QUESTIONS.md).
- Релизы: `SonyX.zip` с `SHA256SUMS.txt`, позже Homebrew cask.
- Сборка в GitHub Actions, чтобы любой мог убедиться, что бинарник собран из кода.
- Подпись Apple Developer ID и нотаризация — отдельный этап, требует платного аккаунта.
